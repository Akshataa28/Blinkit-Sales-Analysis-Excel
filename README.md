# Blinkit Sales Analysis Dashboard (Excel)
## Project Objective
The objective of this project is to analyze Blinkit retail sales performance and customer purchasing patterns using Excel.
This dashboard enables stakeholders to monitor sales trends, compare city and outlet performance, and understand customer preferences through interactive visualizations.

## Dataset used
-   <a href="https://github.com/Akshataa28/Blinkit-Sales-Analysis-Excel/blob/main/Project%20BlinkIT%20Grocery%20Data.xlsx">Dataset</a>

## Questions (KPIs)
- What is the overall sales performance across all outlets?
- Which city contributes the highest sales?
- How do different outlet types perform in terms of revenue?
- Which payment modes are most preferred by customers?
- How does sales vary by region and item category?
- What are the monthly sales trends over the year?
- Which product categories generate the highest sales?

- Dashboard Interaction <a href="https://github.com/Akshataa28/Blinkit-Sales-Analysis-Excel/blob/main/Blinkit_Dashboard.png">View Dashboard</a>

## Process
- Cleaned and prepared raw sales data by handling missing values and standardizing fields using Excel and Power Query.
- Transformed data by creating calculated fields and aggregations with Pivot Tables and formulas.
- Designed an interactive dashboard with slicers for Month, Item Category, City, and Outlet Type.
- Built visualizations and KPI cards to analyze sales by region, city, outlet type, payment mode, product category, and monthly trends.
